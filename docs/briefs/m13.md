# M13 작업 지시서 — UI 전면 정리 (시안 확정 2026-10-26)

M13 — UI 전면 정리 (버전 0.6.0). 브랜치 `claude/m13-ui-overhaul`, base main, PR 하나.
먼저 CLAUDE.md, docs/SPEC.md §14.6·§14.7을 읽고, 아래 설계를 SPEC §14.8로 먼저 적은 뒤 구현한다.
**시안이 기준이다**: `docs/design/m13/*.html` 6장(사용자 승인). 홈(Main), 확인 대기 넓은 창(Pending), 확인 대기 좁은 창(PendingNarrow), 설정-감시 폴더(Settings), 설정-폴더 편집 펼침(SettingsEdit), 설정-규칙(Rules). 각 파일은 `<x-dc>` 안의 마크업이 화면이고 인라인 스타일이 색·간격·크기다. 글귀·순서·구성을 그대로 따르되, 기능 동작은 기존 코드(zustand 스토어·IPC)를 그대로 쓴다.

## 0. 디자인 원칙 (SPEC §14.8에 그대로 적는다)
1. **경로 표기**: 감시 폴더는 **별칭**(기본값: 바탕화면·다운로드·문서·사진은 OS 이름, 그 외는 마지막 폴더 이름; 설정에서 바꿀 수 있음, `[[watch]] alias`)으로 부른다. 전체 경로는 보조 텍스트로 **가운데 생략**(`C:\Users\…\Desktop`: 드라이브+첫 단계와 마지막 1~2단계는 항상 유지, 폭에 맞춰 가운데만 `…`) + title 툴팁에 전체 + 클릭하면 탐색기. 고정폭 글꼴. 공용 컴포넌트 `<PathText path alias? max?>` 하나로 통일하고 모든 화면에서 쓴다. 감시 폴더 안의 출처는 "바탕화면 › 가온누리원 로그"처럼 별칭 › 상대 경로.
2. **한 화면에 한 가지 일, 세부는 눌러야 보임.** 같은 정보를 두 번 보여주지 않는다(정리 위치는 한 번).
3. **반응형**: 창 너비 900px 미만이면 표 → 카드. 긴 설명은 2줄 말줄임 + 더보기. 버튼은 주 버튼 1개 + "⋯" 메뉴. 창 최소 크기 960×640(tauri.conf.json `minWidth/minHeight`).
4. 색·간격: 시안의 값 그대로(`#2457d6` 강조, `#f6f7f9` 바탕, 카드 `#fff` + `#e3e6eb` 테두리 + 10px 모서리, 본문 13~14px, 보조 12px `#6b7280`). styles.css를 토큰(CSS 변수)으로 정리하고 중복 규칙 제거.

## 1. 홈 (Main.html)
- 상태바 한 줄: `● 새 파일 자동 정리 중 │ 감시 4곳 → 정리 위치 D:\정리 │ 인덱스 N │ AI 사용 · 모델`. 일시정지·끊김 상태는 첫 칸이 바뀐다. 누르면 M11의 감시 현황 패널(폴더별 표)이 열린다 — 표도 별칭·PathText로.
- "아직 정리 안 된 기존 파일" 카드: 폴더당 카드 1장(별칭 / 경로 / 큰 숫자 / 새 폴더 N / [지금 정리]). 4열 그리드, 좁으면 2열·1열.
- 아래 2열: "오늘 한 일"(시각 / 이름 / → 목적지, 폴더 항목은 "(폴더 · 파일 N)") + "전체 보기"는 활동 피드로. "고객사별 보기"(M12 데이터) + "사전 편집".
- 활동 피드(기존 목록)는 홈 하단에 접힌 "전체 활동"으로 두거나 "오늘 한 일 → 전체 보기"로 연다.

## 2. 확인 대기 (Pending.html / PendingNarrow.html)
- 상단: [모두] 체크 · "대기 N건 · 선택 M" · [선택한 항목 제안 위치로 이동] [건너뜀] [⋯].
- 넓은 창: 표 5열(체크 / 파일(이름 굵게 + 아래 출처 별칭›상대경로, 폴더면 📁와 "폴더 · 파일 N") / 제안 위치(PathText 한 줄 + 이유 2줄 말줄임) / 제안·확신도(AI 92% 배지 + "새 고객사 폴더"·"새 주제"·"확신 낮음" + 시각) / [이동] [⋯]).
- 확신도 색: 80% 이상 파랑 배지, 미만 주황.
- ⋯ 메뉴: 다른 곳으로… / 이름 바꿔 이동 / 건너뜀(이번만) / 무시(앞으로 묻지 않음) / 대기열에 두기.
- 좁은 창: 같은 항목을 카드로(PendingNarrow.html). 전환은 CSS 컨테이너/미디어 쿼리 900px.
- 확인 팝업(별도 창)도 같은 카드 디자인·같은 ⋯ 메뉴를 쓴다.

## 3. 설정 (Settings.html / SettingsEdit.html / Rules.html)
- **왼쪽 메뉴 + 오른쪽 한 주제**: 감시 폴더 / 규칙 / 업무 맥락(AI 배지) / AI 연결 / 보안·개인정보 / 고급. 메뉴 아래에 "Tidy 0.6.0 · 정보". 기존 접는 섹션 6개를 라우팅으로 바꾼다(`#/main/settings/<key>`), localStorage의 섹션 열림 상태는 더 쓰지 않는다. 좁은 창(900px 미만)에서는 메뉴가 위로 가로 탭이 된다.
- 감시 폴더 화면: 맨 위 "정리 위치" 카드(공통 organize_root, 찾아보기). 폴더마다 카드 1장: 아이콘 + 별칭 + 경로(PathText) / 요약 한 줄("하위 폴더 포함 · 본문 검색 · 정리 위치 D:\정리 · 제외 2개") / 상태(● 정상·끊김·일시정지) / [편집]. "+ 폴더 추가"는 점선 버튼.
- 편집 펼침(SettingsEdit.html): 누른 카드만 펼쳐져 별칭 입력·전체 경로·폴더 열기 / 2열 옵션(하위 폴더 안의 파일도 정리, 파일 안의 글자까지 검색, 종류(내 PC 폴더/네트워크 NAS — NAS면 주기 확인·주기만 사용·본문 인덱싱 시간대가 아래 추가 줄로), 정리 위치(공통 / 이 폴더 안에서 / 다른 폴더…)) / "건드리지 않을 하위 폴더(제외)" 칩 + 추가 / "이 폴더 감시 그만두기"(빨강 링크, 확인). 공통 정리 위치 = 모든 폴더가 collect+같은 root일 때; 폴더별 다른 값은 "다른 폴더…"로 표현(config 구조는 그대로).
- 규칙 화면(Rules.html): 규칙은 **접힌 한 줄**(⋮⋮ 드래그 / 이름 / 조건 요약 / → 목적지 / 지금 N개 / 펼치기). 절대 경로 규칙은 주황 테두리 + "⚠ C:\…\Installers" + "상대 경로로" 링크(M11 변환). 펼친 카드는 하나만(아코디언): 확장자 칩, 이름에 포함, 어디로(입력 + "→ D:\정리\압축 파일" 미리보기 + 폴더 선택), 옵션(옮기기 전에 묻기 · 개인정보면 암호화 · 조건 더 보기). "AI로 규칙 만들기"·"+ 규칙 추가"는 오른쪽 위. rules.toml 직접 편집은 맨 아래 details.
- 다른 설정 화면(업무 맥락·AI 연결·보안·고급)은 기존 내용을 같은 카드 스타일로 옮기고 한 화면씩. 고급에 "무시한 파일", 데이터베이스, 단축키, 조용 모드, 자동 시작, 업데이트 확인, 마법사 다시 실행.
- 저장바는 그대로 하단 고정(변경 취소 / 저장, 경고 문구).

## 4. 정리하기·되돌리기·검색·마법사
- 정리하기: 폴더 선택은 별칭 드롭다운, 미리보기 표는 확인 대기와 같은 행 디자인(폴더 항목 📁), 좁은 창 카드.
- 되돌리기: 묶음 행에 PathText, "자동 이동 한꺼번에 되돌리기"는 카드로 위에.
- 검색 창·마법사: 색·글꼴·버튼만 토큰으로 맞춘다(구조 변경 없음).
